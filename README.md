# holbertonschool-web_front_end

## HTML Advanced

This project builds a complete Techium website through 40 progressive HTML exercises.

- **Tasks 0–5:** Created the initial HTML structure, document metadata, favicons, article page, and main website sections.
- **Tasks 6–13:** Added homepage content, headings, paragraphs, and the first style guide pages.
- **Tasks 14–25:** Structured content with spans and divs, added comments, navigation, social links, calls to action, lists, and footer navigation.
- **Tasks 26–34:** Expanded the style guide with lists, horizontal rules, quotes, typography, tables, and details elements.
- **Tasks 35–39:** Added the Techium image logo, portfolio and blog images, testimonial avatars, SVG social icons, video, and audio players.
- **Task 40:** Completed the style guide with an embedded YouTube iframe.

The final pages include the Techium homepage, About, Latest News, Contact, Article, and Styleguide pages, along with the supporting favicon, logo, and image assets.
